메모를 적고, 찾고, 고정하고, 지우는 한 페이지 웹앱.

## 실행 방법
- 명령: `python app.py <포트>` (의존성 없음)
- 주소: `http://127.0.0.1:<포트>/`
- 환경변수: `MEMO_ADMIN_TOKEN` (`.env`에서 읽음, 화면 기능에는 필요 없음)
- 데이터: `memos.json`. 없으면 예시 메모 2개("장보기: 두부, 대파" 고정됨, "치과 예약 전화")로 시작한다.

## 시작 전제조건
- 서버가 떠 있고 `GET /api/memos`가 200을 준다.
- `memos.json`이 없다 (예시 메모 2개 상태).
- 열린 설정 화면 없음, 검색창 비어 있음.

## 조작 관례
- 격리: 비어 있는 자기 포트로 따로 띄운다. 사용자가 띄운 서버에 붙지 않는다. 끝나면 띄운 PID만 멈춘다.
- 대기: 고정 시간 `sleep`으로 끝났다고 보지 않는다. 끝 상태(`#status` 문구, 목록 항목)를 폴링하고, 10초가 넘으면 멈추고 "건너뜀"으로 보고한다.
- 입력: 좌표 클릭보다 선택자와 `/` 단축키를 쓴다.
- 건드리지 않기: `memos.json`을 손으로 고치지 않는다. 검증 중 만든 메모는 보고에 적는다.

## 기능

### 메모 추가
- 사용자 경로: 첫 화면 → 메모 입력칸 → "추가" 버튼
- 선택자: `#memo-input`, `#add-btn`, `추가`, `#status`
- 파일: `static/index.html`, `app.py::do_POST`
- 검증: 입력칸이 비어 있으면 "추가"가 비활성이다. 글을 넣고 누르면 `#status`가 "저장 중…"이 되고, 서버 응답 뒤(약 0.8초)에 "저장됨"으로 바뀌며 목록에 새 메모가 붙는다 (2026-09-01 실행 확인). 실패하면 "저장 실패" (미확인, 실패 응답을 만들 방법이 화면에 없음).

### 메모 검색
- 사용자 경로: 첫 화면 → 검색창에 입력
- 단축키: `/` (입력칸·검색창에 초점이 없을 때 검색창으로 이동)
- 선택자: `#search`, `[aria-label="메모 검색"]`, `#empty`
- 파일: `static/index.html`, `app.py::do_GET`
- 검증: 입력할 때마다 목록이 글자를 포함하는 메모로 줄어든다. 맞는 메모가 없으면 "메모가 없습니다"가 보인다 (2026-09-01 실행 확인).

### 메모 고정
- 사용자 경로: 첫 화면 → 메모 줄의 "📌 고정" 또는 "고정 해제"
- 선택자: `.pin-btn`, `📌 고정`, `고정 해제`
- 파일: `static/index.html`, `app.py::do_POST`
- 검증: 누르면 서버 응답 뒤 목록이 다시 그려지고, 고정된 메모가 맨 위로 가며 굵게 보이고 버튼이 "고정 해제"로 바뀐다 (2026-09-01 실행 확인).

### 메모 삭제
- 사용자 경로: 첫 화면 → 고정되지 않은 메모 줄의 "삭제"
- 선택자: `.delete-btn`, `삭제`
- 파일: `static/index.html`, `app.py::do_DELETE`
- 검증: 고정된 메모에는 "삭제" 버튼이 없다. 고정되지 않은 메모에서 누르면 서버 응답 뒤 그 줄이 사라진다 (2026-09-01 실행 확인).

### 설정 (다크 모드)
- 사용자 경로: URL `/setting` 직접 입력 → "다크 모드" 체크칸
  - 첫 화면 오른쪽 위 "설정" 링크는 `/settings`로 가서 404가 난다 (앱 버그, 2026-09-01 보고함).
- 선택자: `#dark-mode`, `다크 모드`
- 파일: `static/setting.html`, `app.py::do_GET`
- 검증: 체크하면 배경이 어두워지고, 새로고침해도 체크가 유지된다 (2026-09-01 실행 확인).
