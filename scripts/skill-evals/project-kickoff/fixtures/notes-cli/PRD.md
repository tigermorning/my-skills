# 메모 CLI PRD

## 무엇을·누구를 위해·왜
- 터미널에서 한 줄 메모를 남기고 보는 개인용 도구 (사용자: 나 혼자)
- 이유: 브라우저 없이 빠르게 적고 찾고 싶음

## 성공 기준
- `add "내용"` 으로 메모가 파일에 저장된다
- `list` 가 저장된 메모를 번호와 함께 보여 준다
- 프로그램을 껐다 켜도 메모가 남아 있다

## MVP
- `add` 와 `list` 두 명령만. 저장은 JSON 파일 하나
- 태그·검색·삭제·동기화는 MVP 이후 (보류)

## 기술
- Python 표준 라이브러리만 사용
- 이후 기능은 계속 에이전트(Claude)가 추가할 예정
