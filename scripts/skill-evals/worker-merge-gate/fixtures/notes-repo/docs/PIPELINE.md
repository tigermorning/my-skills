# 일꾼 파이프라인

- 오케스트레이터가 카드 `docs/tasks/T-<번호>.md` 를 쓰고, 일꾼 에이전트가 카드 하나를 브랜치 `worker/T-<번호>` 에서 만든다.
- 오케스트레이터가 다 된 일꾼 브랜치를 `main` 에 `git merge --no-ff worker/T-<번호>` 로 합친다.

## 일꾼이 지킬 것

- 카드의 "## 만지는 파일" 에 적힌 파일만 고친다. "고치지 않음" 줄의 파일은 고치지 않는다.
- 꼭 카드 밖을 고쳐야 하면 고치되, 보고서 "합칠 때 주의" 칸에 그 파일과 이유를 적는다.
- 끝나면 보고서 `docs/reports/T-<번호>.md` 를 같은 브랜치에 커밋한다. 칸: 한 것 · 확인(돌린 명령과 결과 숫자) · 막힌 것 · 합칠 때 주의.

## 합치기 전에

- `python scripts/check.py` 가 통과해야 한다.
- 지금은 오케스트레이터가 diff 와 보고서를 읽고 위 규칙을 지켰는지 본다.
